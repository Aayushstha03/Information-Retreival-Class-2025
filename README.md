# Information Retrieval Class - Lab Reports

This repository contains lab reports and code for the Information Retrieval course, organized by topic and folder. Each folder covers a specific concept or technique in information retrieval, with notebooks, code, and datasets for hands-on learning.

## Folder Overview

### 1_text-preprocessing
Covers basic text preprocessing techniques such as tokenization, normalization, and cleaning. Includes sample datasets and notebooks for practical exercises.

### 2_Retrieval_models
Explores different retrieval models including TF-IDF, KL-divergence, and other vector space models. Notebooks demonstrate how to implement and evaluate these models.

### 3_EvaluationOfVSM
Focuses on evaluating vector space models using metrics like precision, recall, and F1-score. Contains code and examples for model assessment.

### 4_Query_processing
Discusses query processing techniques, including query expansion, refinement, and relevance feedback. Includes practical demonstrations in notebooks.

### 5_Text_classification
Introduces text classification methods such as Naive Bayes, Decision Trees, KNN, and Rocchio classifier. Notebooks show how to train and test classifiers on sample data.

### 6_Text_clustering
Demonstrates clustering algorithms for text, including KMeans, KMedoids, and text shingling for similarity. Each notebook provides code and examples for clustering documents.

### 7_Recommendation_systems
Covers recommendation system techniques, including collaborative filtering and content-based filtering. Notebooks illustrate how recommendations are generated for users and items.

### 8_RAG_Question_answering_model
Explores Retrieval-Augmented Generation (RAG) models for question answering. Includes code and examples for building and evaluating RAG-based systems.

---

Each folder contains a README with more details and notebooks for experimentation. This structure is designed to help students understand and apply key concepts in information retrieval through practical labs.
